## 변경 사유 (Why)

관리자 콘솔 개편에서 대시보드(#84)와 FX 결측 히트맵(#85)을 병렬로 진행하려 했는데,
**두 이슈가 같은 파일 세 곳을 건드려 병렬이 되지 않았다.**

| 파일 | #84 | #85 |
|---|---|---|
| `src/api/admin.ts` | 결측 건수 카드용 조회 | 결측 조회 + 백필 |
| `src/screens/admin/admin-routing.ts` | `dashboard` 라우트·메뉴 | `fxGaps` 라우트·메뉴 |
| `src/screens/admin/admin-app.tsx` | 화면 분기 | 화면 분기 |

게다가 착수 직전에 확인해 보니 **환율 결측 API 의 프론트 클라이언트가 아예 없었다.**
백엔드에는 `GET /admin/fx-rates/gaps` 와 `POST /admin/fx-rates/backfill` 이 오래전부터
있었지만(백엔드 이슈 #116) `src/api/admin.ts` 794줄 어디에도 호출부가 없다. 두 이슈가
각자 같은 클라이언트를 만들 뻔했다.

겹치는 부분을 먼저 깔아 두면 이후 두 이슈가 **각자 자기 화면 파일 하나만** 건드린다.

## 변경 내용 (What)

- `src/api/admin-fx-gaps.ts` 신설 — 결측 조회·백필 클라이언트. `api/admin.ts` 가 이미 커서 붙이지 않고 갈랐다
- `src/api/admin-record.ts` 신설 — `admin.ts` 안에만 있던 응답 리더(`readString` 등)를 옮겼다. 관리자 API 모듈이 여럿으로 갈리면서 같은 리더를 여러 벌 두지 않기 위해서다
- 라우트 두 종 추가 — `dashboard`(`/admin`), `fxGaps`(`/admin/fx-rates/gaps`)
- 메뉴를 2단(묶음 → 항목)으로 개편. 앞으로 마스터·콘텐츠 화면이 묶음째 들어온다(#86·#87)
- 껍데기 화면 2개 — `dashboard/admin-dashboard-screen.tsx`, `admin-fx-gap-heatmap.tsx`

## 영향 / 리스크

**`/admin` 의 착지점이 바뀐다.** 전에는 사용자 목록이었고 이제는 대시보드다. 모르는 경로의
기본값도 사용자 목록에서 대시보드로 바뀌었다. 사용자 목록은 `/admin/users` 로 그대로 갈 수 있다.

**메뉴 문구가 짧아졌다.** 묶음 이름이 앞에 붙으면서 중복을 걷어냈다.

| 전 | 후 |
|---|---|
| 통화 마스터 | 마스터 › 통화 |
| 환율·갱신 | 환율 › 시계열 |
| AI 설명 / AI 추출 / AI 로그 | AI › 설명 / 추출 / 로그 |

**껍데기 화면 2개가 잠시 메뉴에 보인다.** 내부 운영 도구이고 #84·#85 가 곧 채운다.
그 대가로 두 이슈의 파일 충돌이 0 이 된다.

계산에 영향 없음 — 수치를 만들거나 고치는 코드가 없다.
