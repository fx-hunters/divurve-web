## 변경 사유 (Why)

`/xray` 노출 탭이 데스크톱 일부 폭에서 깨져 보였다. 콘텐츠 가로의 약 1/3이 빈 채로 남고,
카드 두 열이 왼쪽에 눌려 손익 분해 테이블이 잘리고 항목 라벨이 한 글자씩 세로로 쌓였다.

원인은 CSS 값이 아니라 `auto-fit` 의 트랙 접기 조건이다.
`repeat(auto-fit, ...)` 는 **비어 있는** 트랙만 0으로 접는데,
같은 그리드의 AI 설명 블록이 `grid-column: 1 / -1` 로 모든 트랙을 가로지르고 있었다.
그래서 카드가 2개뿐인데도 남는 3번째 트랙이 "비어 있지 않은" 상태가 되어 접히지 않았고,
두 카드 열은 `minmax` 하한인 300px 에 그대로 눌렸다.

카드 padding(1.5rem x 2)을 빼면 안쪽이 252px 만 남는데,
그 안의 테이블은 `overflow-x: auto` 에 `min-width` 가 없어 셀이 min-content 까지 붕괴했다.

## 변경 내용 (What)

- `xray-exposure-view.tsx` — 최상단을 flex column 으로 바꾸고, AI 설명 블록을
  2열 그리드의 **자식이 아니라 형제**로 내렸다. `gridColumn: "1 / -1"` 제거.
- `layout.css` — 쓰이지 않던 `.responsive-grid-2col` 을 결정적 정의로 고쳤다.
  `auto-fit` 대신 768px 미만 1열 / 이상 `repeat(2, minmax(0, 1fr))`.
  트랙 수가 항상 정확히 2개라 유령 트랙이 생길 수 없다.
- `xray-exposure-view.tsx` / `xray-fitness-view.tsx` — 인라인 그리드 style 을
  위 클래스로 교체했다. 적합도 탭은 현재 정상이지만 같은 패턴이라 함께 옮겼다.
- 손익 분해 `<table>` 에 `min-width: 17.5rem` 을 줘서, 좁은 폭에서 셀이 붕괴하는 대신
  wrapper 가 가로 스크롤되게 했다.

## 영향 / 리스크

계산·API·데이터 형태 변경 없음. 표시 레이아웃만 바뀐다.

`/xray` 노출 탭 계측값 (뷰포트 1264px, 배포본 대비):

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| `grid-template-columns` | `302px 302px 302px` | `465px 465px` |
| 손익 분해 wrapper 폭 | 252px | 415px |
| 테이블 오버플로 | 잘림 (스크롤바 없음) | 없음 |
| 항목 셀 높이 | 71px (3줄 붕괴) | 50px (1줄) |

폭별 확인 (변경 후):

| 뷰포트 | 트랙 | 테이블 오버플로 | 항목 셀 높이 | 페이지 가로 스크롤 |
|---|---|---|---|---|
| 1440 | `553px 553px` | 없음 | 50px | 없음 |
| 1264 | `465px 465px` | 없음 | 50px | 없음 |
| 1024 | `345px 345px` | 없음 | 50px | 없음 |
| 768 | `353px 353px` | 없음 | 50px | 없음 |

리스크: `.responsive-grid-2col` 의 브레이크포인트가 768px 로 고정된다.
기존 인라인 정의는 `min(100%, 300px)` 기준이라 컨테이너 폭에 따라 접혔는데,
이제 뷰포트 기준이다. 사이드바가 사라지는 `max-width: 768px` 규칙과 경계가 같아
`/xray` 에서는 동작이 같다. 이 클래스를 다른 화면에 쓸 때는 확인이 필요하다.
