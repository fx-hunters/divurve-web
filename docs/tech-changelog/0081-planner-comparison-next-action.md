## 변경 사유 (Why)

PR #117의 배포 GUI에서 일본 1회차 기록 후 확보액 75,000 JPY, 다음 행동 2회차,
상세 왕복·비교 취소의 기록 보존은 확인됐다. 그러나 비교 표의 기존 다음 행동은
정적 scenario 문구를 읽어 9월 14일 첫 회차를 다시 안내했다. 미국도 같은 경계를 사용했다.

## 변경 내용 (What)

비교의 기존 다음 행동은 메인과 같은 `presentDemoPlanner`의 현재 ViewModel에서
가져온 회차 번호·날짜·외화 금액으로 표시한다. 제공된 다음 회차가 없다면 이를 알리며
첫 회차나 목표 달성을 만들어 표시하지 않는다. 완료 기록, 금액, 시나리오 계산,
API 요청·저장 정책 및 UI 레이아웃은 변경하지 않는다.

- 메인/비교가 같은 현재 기록을 사용하고 완료 후 첫 회차를 되살리지 않는지 검증한다.
- 수정 후 관련 2파일 38테스트 통과(23.11초).
- 최종 전체 coverage: 141파일, 1,278테스트 통과. 네 항목 100%, 종료 0(404.06초).
- ESLint 오류 0, 기존 경고 17, 종료 0(11.72초).
- TypeScript 포함 build 종료 0, 830모듈, JS 951.34kB(38.92초). 기존 청크 경고 유지.
- diff 공백 검사 통과. 후속 CI·배포 GUI 결과는 PR 및 개인 검수 보고서에 별도 기록한다.

## 롤백 방법

이 후속 수정 커밋을 revert하는 새 커밋으로 되돌릴 수 있다. 금액·기록·서버 저장에는
변경이 없으며, revert 시 비교 문구의 기존 불일치가 재발한다. 공유 이력을 강제 변경하지 않는다.
