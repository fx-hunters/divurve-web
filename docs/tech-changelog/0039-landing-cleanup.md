## 변경 사유 (Why)

랜딩 페이지가 서비스 메시지와 어긋난 채 남아 있었다.

1. **근거 없는 수치가 노출됐다.** `id="stats"` 섹션(네비 라벨 "성과 지표")의 "목표 환전 단가 방어율 94.8%", "리스크 노출 방어 효율 4.2배" 같은 값은 백엔드가 산출하지 않는, 출처 없는 마케팅 수치였다. 계산 결과는 전부 BE에서 받아 표시한다는 원칙(AGENTS.md §1)과 정면으로 어긋나 섹션째 걷어냈다.
2. **어원 섹션은 전환에 기여하지 않았다.** 히어로에서 CTA까지 가는 길에 브랜드 이름 풀이가 한 화면을 차지하고 있어 스크롤 비용만 늘렸다.
3. **CTA 문구가 제각각이었다.** 헤더 "무료 시작", 히어로 "대시보드 체험하기", 하단 "대시보드로 바로가기"가 실제로는 모두 같은 가입/진입 동선인데 서로 다른 기대를 만들었다.
4. **네비가 현재 위치를 알려주지 않았다.** 헤더는 이미 sticky였으나 어느 섹션을 보고 있는지 표시가 없어 긴 페이지에서 방향 감각이 없었다.
5. **히어로 팬 차트의 과거 구간이 사실상 일직선이었다.** Y축 도메인이 신뢰밴드(1280~1460)에 맞춰 잡히는데 과거 곡선의 진폭이 38원(1312~1350)뿐이라 화면 높이의 17%만 쓰며 평평하게 보였다. "환율 곡선을 다루는 서비스"라는 첫인상을 스스로 깎고 있었다.
6. **금지어가 UI 문구에 남아 있었다.** "예측", "추천"이 헤드라인·피처·스텝 문구에 그대로 있었다(AGENTS.md §6 / 네이밍 문서 6장).

## 변경 내용 (What)

- **삭제**: `id="etymology"` 섹션 전체, `id="stats"` 섹션 전체(+`STATS` 상수), 두 섹션을 가리키던 네비 링크("어원", "성과 지표"), 두 섹션용 `useInView` 호출.
  - 이슈 요구사항 2번(‘성과 지표’ 섹션 제거)과 7번(`id="stats"` 설명 텍스트 높이 정렬)은 **같은 섹션**을 가리킨다. 네비의 `<a href="#stats">성과 지표</a>`가 그 섹션의 유일한 진입점이고, 섹션 주석도 "성과 통계(Stats)"였다. 제거가 우선이므로 7번은 무효 처리했다.
- **신규 훅** `src/hooks/use-scroll-spy.ts` — 섹션 id 배열을 받아 현재 화면에서 가장 크게 노출된 섹션 id를 돌려준다(`IntersectionObserver` 기반, 값만 반환 — §7.3). `IntersectionObserver`가 없는 환경에서는 `null`을 유지한다.
- **네비** — 이미 적용돼 있던 `position: sticky`를 유지하고, 스크롤 스파이 결과에 따라 활성 탭에 `color: var(--primary)` + 하단 보더 + `aria-current="true"`를 준다. 링크는 `NAV_SECTIONS` 상수에서 렌더한다.
- **문구**
  | 위치 | 변경 전 | 변경 후 |
  |---|---|---|
  | 헤더 CTA | 무료 시작 | 회원가입 |
  | 히어로 헤드라인 | 가장 지능적인 환전 타이밍 | 가장 지능적인 환전 가이드 |
  | 히어로 서브 | 환율 범위 예측 | 환율 전망 |
  | 히어로 CTA | 대시보드 체험하기 | 무료로 시작하기 |
  | 하단 CTA | 대시보드로 바로가기 | 무료로 시작하기 |
  | 피처 카드 | 몬테카를로 팬 차트 **예측** | 몬테카를로 팬 차트 전망 |
  | 스텝 02 | 환율의 **예상** 경로 | 환율의 투영 경로 |
  | 스텝 03 | 회차별 **추천** 수량 | 회차별 제안 수량 |
  | 하단 CTA 본문 | 복잡한 환율 **예측**과 | 복잡한 환율 전망과 |
- **히어로 팬 차트** — 과거 구간 곡선을 굴곡 있는 장식용 더미 값으로 교체(진폭 38 → 76). 상수에 "장식용 더미 곡선" 주석을 남기고, `type="monotone"`으로 부드럽게 그린다.

## 영향 / 리스크

- **오인 방지 조치**: 더미 곡선이 실제 시세로 읽히면 안 되므로 (a) 카드 eyebrow를 `LIVE PREVIEW` → `SAMPLE PREVIEW`로, (b) 범례 "실제 환율" → "관측 구간"으로 바꾸고, (c) "화면 구성을 보여주는 표시용 샘플 곡선입니다. 실제 시세가 아닙니다." 문구를 붙였다. (d) Y축은 기존대로 `hide`를 유지하고, **수치를 노출하던 `<Tooltip>`과 `formatLandingTooltipValue`를 제거**했다 — 장식용 데이터에 ₩ 금액 라벨이 붙는 것이 가장 큰 오인 요소였다.
- 곡선 값 변경 전후 (장식용, 계산·API와 무관):

  | 밴드 상단(12월) | 1460 | 1440 |

- **범위 밖 파일 1건 수정**: `src/app/app.test.tsx`가 랜딩 CTA를 `/대시보드 체험하기/`, `/무료 시작/`, `"가장 지능적인 환전 타이밍"`으로 조회하고 있어 문구 변경과 함께 깨진다. 셀렉터 문자열만 갱신했다(히어로·하단 CTA가 같은 이름이 되므로 `getAllByRole(...)[0]`로 바꿈). 앱 로직은 건드리지 않았다.
- 네비 항목이 4개 → 2개("기능", "작동 방식")로 줄었다. 768px 이하에서는 `.landing-nav`가 원래 숨겨지므로 모바일 영향 없음.
