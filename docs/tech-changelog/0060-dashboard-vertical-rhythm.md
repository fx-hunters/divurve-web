## 변경 사유 (Why)

#71로 카드 배치를 다시 짠 뒤 실제 화면(1330×892, 가시 영역 785px)을 재보니 세 가지가 남아 있었다.

| 요소 | 높이 | 문서 상 위치 |
|---|---|---|
| 오늘의 핵심 | 75 | 88 – 163 |
| 오늘의 시장 | 685 | 187 – 872 |
| └ 그중 AI 설명 | 188 | 659 – 847 |
| 오른쪽 기둥 | 809 | 187 – 996 |
| 경제 일정 | 430 | **1020 – 1450** |

1. 시장 카드(685)와 오른쪽 기둥(809)의 하단이 124px 어긋난다.
2. AI 설명이 늘 펼쳐져 있어 접을 수단이 없다.
3. "주의 필요" 뱃지가 붙은 경제 일정이 첫 화면 밖(top 1020)에 있다.

**세 문제는 따로 풀 수 없다.** AI 설명(188px)을 그냥 접으면 시장 카드가 483px이 되어 격차가 124 → 326px로 **더 벌어지고**, 토글할 때마다 페이지가 124px씩 출렁인다. 그래서 "카드 바깥 높이를 고정하고 남는 높이를 그래프가 흡수한다"는 한 가지 장치로 1·2를 함께 풀었다.

3은 산술적으로 다르다. 헤드라인(75) + 본문(809) + 간격만으로 이미 996px이라 785px 안에 네 카드를 넣는 방법이 없다. 옮기는 대신 **쪼갰다** — 신호(고변동성 일정 2건)만 헤드라인 띠로 올리고 세부는 카드에 남겼다.

## 변경 내용 (What)

- `market-summary-card.css`: 카드 `height: 100%`, 본문 `flex: 1`, 그래프 `flex: 1`. 데스크톱(≥1024px)에서는 svg 를 `position: absolute` 로 띄운다.
- `home-dashboard.css`: `.home-dashboard__market { align-self: stretch }` (데스크톱만).
- `use-element-size.ts` (신규): 요소의 실제 렌더 크기를 잰다. 렌더마다 `useLayoutEffect` 로 재고, 창 크기 변경은 `ResizeObserver` 로 받는다.
- `trend-chart.tsx`: `viewBox` 를 잰 픽셀 크기로 다시 잡는다. 하한 240×140.
- `use-persisted-toggle.ts` (신규): 펼침/접힘을 `localStorage` 에 기억한다.
- `ai-explanation.tsx`: `isOpen`·`onToggle` prop 을 받아 접기 버튼을 그린다. 상태는 갖지 않는다.
- `market-summary-section.tsx`: 토글 상태를 소유한다. 키 `divurve_ai_explanation_open:home_market_summary`, 기본 펼침.
- `home-presenter.ts`: `toShortDateLabel`, `toHeadlineEvents`(고변동성만 앞에서 2건) 추가. `UpcomingEventItem` 에 `shortDateLabel` 추가.
- `today-headline-card.tsx` + `.css`: 일정 칩 줄 추가.

## 영향 / 리스크

**측정값 (실서버 · 데모 계정 · 목표 1개 기준)**

| 항목 | 전 | 후 |
|---|---|---|
| 시장 카드 하단 | 872 | **826** |
| 오른쪽 기둥 하단 | 996 | **826** |
| 하단 격차 | 124px | **0px** |
| 추세 그래프 | 253px (비율 고정) | 158px → 접으면 **293px** |
| 헤드라인 띠 | 75px | 117px (칩 줄 포함) |
| AI 설명 접었을 때 카드 높이 | — | **597px 그대로** (출렁임 없음) |

오른쪽 기둥이 길어지는 경우도 확인했다. 리스트 높이를 264px(목표 6개 상당)로 두면 오른쪽 기둥 790 → 시장 카드도 790으로 따라오고 그래프가 158 → 351로 자란다. **어느 쪽이 길든 하단이 맞는다.**

**왜 svg 를 띄웠나** — 그리드 행 높이는 각 칸의 max-content 로 정해진다. svg 가 흐름 안에 있으면 제 비율만큼의 높이(약 253px)가 시장 카드의 max-content 에 얹혀, 카드가 오른쪽 기둥보다 커지는 순간 행 높이를 자기가 정하고 이번엔 오른쪽 아래가 빈다. 띄우면 이 자리의 max-content 는 `min-height` 뿐이라 행 높이는 늘 오른쪽 기둥이 정한다.

**왜 렌더마다 재는가** — `ResizeObserver` 의 통지에만 기대면, 통지가 늦거나 오지 않는 환경에서 좌표계가 낡은 채로 남아 그림이 편지봉투처럼 축소된다(실제로 검증에 쓴 브라우저가 그랬다). AI 설명이 도착하거나 접히는 변화는 모두 같은 렌더 안에서 일어나므로 렌더 시점 측정이 더 확실하다. 크기가 같으면 같은 객체를 유지해 재렌더는 없다.

**남는 것** — 경제 일정 카드 자체는 여전히 첫 화면 밖이다. 이번 변경은 "무엇을 봐야 하는지"만 위로 올린 것이고, 카드를 첫 화면에 넣으려면 시장 카드를 잘라야 해서 하지 않았다.

**계약 무관** — API 요청·응답은 그대로다. `shortDateLabel` 은 서버 값(`event.date`)에서 파생한 표시용 문자열이다.
