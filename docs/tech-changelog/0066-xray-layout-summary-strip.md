## 변경 사유 (Why)

[0065](0065-xray-exposure-grid-phantom-track.md) 로 유령 트랙을 없앤 뒤에도 노출 탭의
카드 배치가 정돈되지 않았다. 1440px 실측 기준 좌측은 252/144/103 세 장, 우측은
494/157 두 장이라 카드 경계선이 한 군데도 맞지 않았고 좌측 하단에 128px 이 비었다.

구체적으로 다섯 가지가 겹쳐 있었다.

1. 103px 카드와 494px 카드가 같은 테두리·padding·배경을 써서 시각적 무게는 같은데
   정보량이 5배 달랐다.
2. `환율 민감도` 는 라벨 한 줄 + 값 한 줄이 전부라 카드일 이유가 없었다.
3. 스트레스 시나리오는 157px 인데 시나리오를 고르면 결과 박스가 붙으며 급팽창해
   2열 안에서 행 전체 높이를 끌고 다녔다.
4. 손익 분해 3열 테이블이 반폭에 갇혀, 0065 의 `min-width` 로 붕괴만 겨우 막은 상태였다.
5. 모수가 다른 큰 금액이 서로 다른 카드에 흩어져 있었다 — 총 자산(전체) / 외화 자산 /
   현재 평가액(`attribution`, 매입원가 기준). 라벨만으로 무엇의 합계인지 구분되지 않았다.

## 변경 내용 (What)

홈 대시보드(`home-dashboard.css`)가 쓰는 배치 언어를 그대로 따랐다 — 화면 전용 CSS
파일에 이름 붙인 그리드, `minmax(0, 1fr)`, 명시적 트랙 수, `align-items: start`,
DOM 순서 = 화면 순서.

- **`xray-layout.css` (신규)** — 두 탭 공통 그리드. 1열(모바일) / 768px 이상 2열.
  `__full` 은 전폭, `__pair` 는 2행에서 아래 변을 맞춘다. 요약 스트립은 1/2/4열로
  나뉘며 칸 사이 1px 틈으로 배경이 비쳐 구분선이 된다.
- **`xray-summary-strip.tsx` (신규)** — 두 탭이 공유하는 표현 컴포넌트. 값은 이미
  포맷된 문자열로 받고 숫자 가공은 하지 않는다(AGENTS.md §7.2).
- **노출 탭** — `외화 비중` 카드의 금액 3줄과 `환율 민감도` 카드를 스트립으로 흡수했다.
  남은 도넛과 통화별 게이지는 `통화 구성` 한 장으로 합쳐 손익 분해와 무게를 맞췄다.
  스트레스 시나리오와 `종목별 상세` 는 전폭으로 내렸다.
- **커지는 블록은 2열 밖으로** — `종목별 상세` 아코디언이 손익 분해 카드 안에 있으면
  펼칠 때 2열 행 높이가 통째로 늘어나 옆의 통화 구성 카드까지 494 → 598 로 같이
  커졌다. 전폭 블록으로 분리해 펼쳐도 두 카드가 423 으로 고정되게 했다. 스트레스
  시나리오·비중 조정 시뮬레이터와 같은 규칙이다.
- **남는 높이는 도넛 블록이 흡수** — 카드의 `justify-content: space-between` 에 맡기면
  제목과 첫 블록 사이에 61px 짜리 빈 구멍이 생겨 데이터가 빠진 것처럼 보였다.
  남는 높이를 도넛 블록 하나가 받아 도넛이 그 안에서 가운데 서게 했다.
- **적합도 탭** — 같은 스트립을 얹고, `집중도 진단` 카드의 대형 숫자는 스트립으로
  올렸다. 카드에는 집중도와 기준선을 나란히 세우는 게이지를 넣었다. 비중 조정
  시뮬레이터는 전폭으로 내렸다.
- **모수 표기** — 도넛 소제목에 `총 자산 대비`, 게이지 소제목에 `외화 자산 대비` 를
  붙였다. 실제로 `fxRatio` 는 총 자산 대비(8M/20M), `exposure[].share` 는 외화 자산
  대비(6M/8M)로 모수가 다르다.

## 영향 / 리스크

계산·API·데이터 형태 변경 없음. 표시 배치만 바뀐다.

**노출 탭 카드 높이 (뷰포트 1440px)**

| 블록 | 변경 전 | 변경 후 |
|---|---|---|
| 요약 스트립 | 없음 | 145 (전폭) |
| 좌측 | 외화 비중 252 / 통화별 노출 144 / 환율 민감도 103 | 통화 구성 **423** |
| 우측 | 손익 분해 494 / 스트레스 시나리오 157 | 손익 분해 **423** |
| 종목별 상세 | 손익 분해 카드 안 | 63 (전폭, 펼치면 128) |
| 스트레스 시나리오 | 우측 컬럼 157 | 157 (전폭) |
| 좌우 하단 어긋남 | 128px | **0px** |
| 제목~첫 블록 여백 | — | 24px (정상 gap) |
| 종목별 상세를 펼쳤을 때 두 카드 | 494 → 598 (같이 커짐) | 423 → **423** (변화 없음) |

**적합도 탭** — 집중도 진단 246 / 쏠림을 고치는 방법 246 (좌우 일치).

|---|---|---|---|---|
| 1440 | 2열 553px | 4열 | 없음 | 없음 |
| 1024 | 2열 345px | 4열 | 없음 | 없음 |
| 768 | 2열 353px | 2열 | 없음 | 없음 |
| 480 | 1열 442px | 2열 | 없음 | 없음 |

리스크:

- 노출 탭에서 `외화 비중`·`통화별 노출` 이 카드 제목(h2)에서 카드 안 소제목(h3)으로
  내려갔다. heading role 로는 그대로 잡히지만, 제목 계층을 기준으로 하는 코드가
  생기면 확인이 필요하다.
- `환율 민감도` 라는 제목이 사라지고 스트립 라벨 `환율 1% 상승 시` 가 됐다. 값 색은
  기존 `var(--normal)`(상태색)에서 기본 텍스트색으로 바꿨다 — 민감도는 크기이지
  좋고 나쁨이 아니라 상태색을 쓸 자리가 아니다(컨벤션 7.2).
